### 🔎 DataTrace

<b>AI-Powered Data Lineage & Root Cause Analysis Platform</b>

<p>
DataTrace is designed to help data engineers understand data pipeline
failures by tracing the origin of problems, identifying their causes,
and determining downstream impact.
</p>

<b>Key Questions:</b>

```text
Where did the problem start?
            ↓
Why did it happen?
            ↓
What will be affected?
```

<b>Example:</b>

```text
ETL Pipeline ❌
       ↓
Orders Table
       ↓
Sales Dashboard
       ↓
Revenue Dashboard
```

<b>Technology:</b>

`Python` `FastAPI` `RAG` `LLMs` `FAISS` `Kafka` `Spark` `PostgreSQL`
